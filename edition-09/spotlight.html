🤖 feature/tooling BiomeJS DX LLM biome.json
BiomeJS no projeto — padronização para agentes LLM
❌ problema
Codebase sem padronização consistente de lint/format gerava ruído e diffs inflados; agentes LLM (assistentes de código) recebiam contexto sujo e inconsistente, reduzindo a qualidade das sugestões.
✓ solução
→ Adoção do BiomeJS como linter + formatter único (substitui ESLint+Prettier)
→ Regras padronizadas no repo
→ Formatação/lint rapidíssimos em Rust
→ Integração no fluxo de desenvolvimento
📈 resultado
Diffs menores e previsíveis, menos ruído em PRs, e melhor assistência dos agentes LLM por consumirem código padronizado. Bônus: melhoria de performance do Form-Dinâmico (#13297) com refatoração offline-first (repositório como fonte da verdade).

Importação de Lotes + Calculadora de Solo
❌ problema
Cadastro manual de lotes de gado pesado e recomendação de solo era trabalhoso e sujeito a erro; produtores/técnicos precisavam calcular previsão de abate manualmente.
✓ solução
1. Importação de Lotes via planilha/CSV do Gado Pesado, criando lotes automaticamente com as pesagens e preenchendo a previsão de abate.
2. Calculadora/Recomendação de Solo com telas de análise de solo, aplicação, recomendações e formulação NPK.
📈 resultado
Fluxo de cadastro muito mais simples e rápido, previsão de abate automática usada pela JBS, e nova capacidade de recomendação de solo/NPK no app.

// Data de abate = Data da pesagem + ceil((PAB - PT/N) / GMD)

function calcularPrevisaoAbate(dataPesagem, pesoAlvoAbate, pesoTotal, numCabecas, ganhoMedioDiario) {
  const pesoMedio = pesoTotal / numCabecas
  const kgFaltantes = pesoAlvoAbate - pesoMedio
  const diasNecessarios = Math.ceil(
    kgFaltantes / ganhoMedioDiario
  )
  const dataAbate = addDays(dataPesagem, diasNecessarios)
  return dataAbate
}

⚡ feature #13325 IA CheckWork auditoria-despesas.service.ts
Auditoria de despesas com IA
❌ problema
Auditoria manual de despesas (notas/recibos) no CheckWork era lenta e sujeita a fraude/erro; sem controle de itens permitidos nem visibilidade do custo de IA.
✓ solução
→ Instruções de IA com White/BlackList de produtos/termos permitidos
→ Indicador de SCORE de confiança da resposta da IA
→ Registro do custo de tokens consumidos na análise de imagens
→ Modelagem das entidades ExpenseType e Expense
📈 resultado
Auditoria automatizada com controle por lista, transparência de custo por análise e maior confiabilidade na aprovação de despesas.
